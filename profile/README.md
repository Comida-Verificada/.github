# Comida Verificada

Banco de dados aberto e científico de **produtos alimentícios, ingredientes e aditivos** — com transparência sobre componentes e limitações por país.

## Repositórios

| Repo | Visibilidade | Função |
|------|--------------|--------|
| [platform](https://github.com/Comida-Verificada/platform) | Privado | Apps (mobile/web), backend, banco operacional, infra |
| [landing_page](https://github.com/Comida-Verificada/landing_page) | Privado | Site institucional |
| [ai-components](https://github.com/Comida-Verificada/ai-components) | Privado | IA de busca/normalização/tradução de componentes |
| [ai-regulatory](https://github.com/Comida-Verificada/ai-regulatory) | Privado | IA regulatória (limitações por país) |
| [comida-verificada-public-datasets](https://github.com/Comida-Verificada/comida-verificada-public-datasets) | **Público** | CSVs para auditoria externa (componentes, traduções, limitações) |

## Open source

Publicamos **apenas CSVs** curados para auditoria — sem dados de usuários/listas e sem o código das IAs.
